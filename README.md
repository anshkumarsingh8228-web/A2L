# Alone2Lone G Profile v7

New copy based on v6. v6 is not modified.

This version adds only the currently requested items:
- Friends section inside Profile
- New Chat flow for existing friends after a chat is deleted
- Friends / Strangers / Requests tabs inside Chats
- Accepted friends move their chat category from Strangers to Friends
- Chat request state handling (including cross-tab request events)
- Emoji reaction composer behavior retained/organized
- Permanent Like behavior retained
- Reconnect moved into the Profile/Friends area
- Reliable room mic/camera repeatable toggling retained
- Bottom navigation item renamed from A2L Hub to A2L Rooms and routes directly to Rooms

Previously completed/excluded changes were not intentionally reworked in this version.
